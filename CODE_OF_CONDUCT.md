# Code of conduct

## Our standard

We are committed to a welcoming, harassment-free project for everyone. Be respectful, assume good intent while addressing concrete impact, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discriminatory language, threats, sustained disruption, publishing another person's private information, or sexualized attention.

## Project spaces

This standard applies in repository issues, pull requests, reviews, discussions, and other spaces where someone represents the project.

## Enforcement

Report conduct concerns privately using the repository's configured maintainer-contact mechanism. If no private contact is listed, open an issue titled “Private conduct contact requested” without names or incident details; a maintainer should then arrange a private channel. Do not publish sensitive reports in an issue.

Maintainers may edit or remove contributions, temporarily restrict participation, or permanently ban participants when necessary to protect the community. Reports should be handled confidentially and without retaliation.
