# Support

This community-maintained starter does not include a commercial support agreement or response-time guarantee.

## Where to ask

- Use a bug report for a reproducible defect in the unmodified starter.
- Use a feature request for a reusable improvement with clear completion criteria.
- Use GitHub Discussions, when enabled, for setup questions and implementation ideas.
- Follow [SECURITY.md](./SECURITY.md) for vulnerabilities; do not disclose them in a public issue.

Questions about a derivative product's backend, accounts, billing, provider credentials, deployment, or private infrastructure belong to that product's maintainers.

## Safe diagnostic information

Include the starter version or commit, Node.js version, browser, route, viewport, reproduction steps, and the exact command that failed. Remove credentials, personal data, private hostnames, local absolute paths, and account identifiers before posting.
